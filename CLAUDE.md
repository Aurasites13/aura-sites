# Aura Sites — project context

Aura Sites is an AI-assisted web design studio. The brand promise: "Websites that feel handcrafted, at a pace that isn't." Fast and beautifully designed, deliberately not positioned as an "AI website builder" — AI is the tool behind the scenes, never the sales pitch. Avoid AI-website-builder cliches (templated look, generic layouts).

## Visual language
- Palette: near-black background (#000000/#05060A), electric cyan (#4DE8FF), deep blue (#1F8FE8), warm white text (#EAF6FF), muted gray-blue for secondary text (#6E8291). TRON Legacy-inspired: black void, glowing cyan lines, minimal competing colors.
- Typography: Space Grotesk for headings/display, Inter for body text.
- Motion: smooth, Apple-level polish. Eased transitions, no jank. Restraint over spectacle — quick and quiet animations, not showy.
- Portfolio case-study mockups each get their own distinct palette (to show design range) while the site chrome around them stays in the core brand palette.

## Pricing (yen, tiers)
- Launch: ¥180,000, ~3 day turnaround, up to 3 pages
- Grow: ¥480,000, ~1-2 week turnaround, up to 8 pages (most popular tier)
- Studio: custom quote, scoped per project, unlimited pages/complex builds
- Hosting: optional add-on, ¥3,500-5,000/month, independent of tier (not bundled into any package)
- Process is identical across all tiers (Discovery call -> First look -> Live), only the day-counts differ per tier

## Copy rules
- Never use em dashes ("—") anywhere in generated copy.
- Sentence case, plain everyday language over corporate jargon.
- Unfamiliar terms (domain, hosting, CMS) get a short one-sentence explanation via a ⓘ-tap affordance, not a permanent paragraph.

## Design philosophy
- Ergonomics first: minimize taps/friction, prefer smart defaults and skippable steps over mandatory ones.
- One signature "wow" moment is memorable; several competing ones feel like showing off. Don't stack multiple big scroll-hijacked moments on one page.
- Portfolio only features real or in-progress work (JINGU, Luxury Japan, PEC) with honest status labels (e.g. "In progress" instead of a live link when not yet launched).
